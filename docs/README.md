# Dokumentationsreferenser

## Motor Motion Protocol

`Motor_Motion_Protocol.pdf` finns inte i detta repository och ska inte
återskapas eller ersättas med en gissad PDF. Den kanoniska interna textkällan
för den återanvända motorintegrationen är
[`remote_control/docs/design/protocol.md`](../../remote_control/docs/design/protocol.md).
Den dokumenterar att den verifierade PDF-källan är *RMD-X Servo Motor Control
Protocol V3.8.pdf* och beskriver projektets validerade protokollanvändning.

När den auktoritativa PDF:en blir tillgänglig ska den läggas till genom en
spårbar dokumentationsprocess och dess version/proveniens verifieras mot den
interna textkällan. Ändra inte motorprotokoll, ID:n, riktning, skalning eller
tidsgränser utifrån denna referenssida.

## Övrigt material

HIL-material och återanvändningsinventering finns kvar under `docs/`.
Projektets funktionella krav och arkitektur finns under `requirements/`.
